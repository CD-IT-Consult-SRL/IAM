## Governance Question

```text
CAN we grant it?
```

is technical.

```text
SHOULD we grant it?
```

is governance.

## IGA vs PAM

```text
IGA
=
Who SHOULD have access?
```

```text
PAM
=
Control USE of privileged access
```

# 10-Second Memory

```text
IGA = GOVERNANCE

JML = lifecycle

Request = new access

SoD = conflict

Recertify = still needed?

Reconcile = expected vs actual

Correlate = account -> identity

Remediate = actually fix it

Audit = prove it
```

> IAM controls access. IGA governs why that access should exist and whether it should continue to exist.
